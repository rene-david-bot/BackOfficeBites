# Cash Flow Forecast Command Center

## User Story
As a finance operations lead, I want to model cash flow scenarios with clear policy checks so I can secure approvals and keep stakeholders aligned on runway risk.

## Features
- Scenario builder with growth, churn, opex, and DSO controls
- Base vs active scenario line chart
- Search, filter, and sort forecast line items
- Approval queue with approve/reject actions
- Role-based confidence visibility (CFO view)
- CSV export for finance reporting
- Auto-updating audit trail with timestamps

## Dave's Notes
- Dark-mode only, Tailwind via CDN, static + interactive.
- Policy triggers surface approval workflow for high-risk assumptions.
- Forecast math is simplified but realistic for demos.
