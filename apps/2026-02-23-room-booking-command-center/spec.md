# Room Booking Command Center

## User Story
As a workplace operations manager, I want to govern room bookings in one calendar view so I can enforce policies, prevent conflicts, and keep an audit trail of approvals.

## Features
- Weekly calendar view with room focus filter
- Policy-aware booking form (after-hours, capacity overrides, exec events)
- Conflict detection before submission
- Approval queue with approve/reject actions
- Search, filter, and sort booking ledger
- CSV export for compliance reporting
- Auto-updating audit trail

## Dave's Notes
- Dark-mode only, Tailwind via CDN, static + interactive.
- Policies are intentionally strict to demonstrate approval routing.
- Seeded with realistic ops scenarios and exception handling.
