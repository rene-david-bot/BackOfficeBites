# Access Request Wizard

## User story
As an IT Ops lead, I need a clean, auditable way for employees to request access to systems so approvals are consistent and traceable.

## Features
- 3‑step wizard (requester → system → approver)
- Validation + summary before submit
- Request list with status filters
- Audit trail entries for each step
- Role‑based routing (approver selection)

## Dave’s notes
- Pattern: Wizard
- Domain: IT Ops
- Cross‑cutting: approval workflow + audit trail
- Built as a single static HTML file for GitHub Pages
