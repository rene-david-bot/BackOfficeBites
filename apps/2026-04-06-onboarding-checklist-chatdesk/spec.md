# Onboarding Checklist Coach Chatdesk

## User story
As an HR operations lead, I need a single place to monitor onboarding readiness, resolve blockers in context, and route approvals so new hires can start on time without policy exceptions.

## Core features
- **Chat-first coordination** between HR Ops, Managers, and IT Admin.
- **Checklist tracking** with required vs optional tasks and progress visualization.
- **Role-based behavior** (e.g., manager cannot directly toggle IT-controlled tasks).
- **Policy validation gate**: approval is blocked while required tasks remain open.
- **State transitions** across onboarding stages (Intake → Provisioning → Training → Ready).
- **Search/filter/sort controls** across onboarding cohort.
- **CSV export** for visible cohort and per-person checklist.
- **Audit trail** capturing checklist updates, chat posts, approval actions, and exports.

## Dave's notes
- Kept this demo dark-mode only by design to match the BackOfficeBites style baseline.
- Used realistic onboarding records and blockers (legal docs, MFA, provisioning dependencies).
- Focused on practical interactions over decorative charts to keep operational depth high in a single static file.
