# Policy-Aware Expensing Wizard

## User Story
As a traveling employee, I need to capture expenses quickly and know instantly if I’m within policy so I can submit a compliant report that flows through manager and finance approvals without delays.

## Core Features
- Wizard-style expense capture with auto-category and VAT hints
- Real-time policy guardrails (caps, receipt rules, weekend flags)
- Risk score banner per report with approval requirements
- Manager + finance approval queue with search, filter, and sorting
- Role-based views for employee, manager, and finance perspectives
- Audit trail for key actions and policy events
- Status flow from submission to reimbursement

## Dave’s Notes
- Dark-mode only layout with a wizard + approval queue hybrid
- Live policy evaluation drives the risk score and suggested actions
