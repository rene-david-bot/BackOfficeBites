# RACI Builder Studio

## User story
As a program manager, I need to build and validate RACI plans across initiatives so I can lock accountable owners, route approvals, and keep stakeholders aligned before kickoff.

## Features
- Master-detail initiative list with search, filters, sorting, and role-based view dimming.
- Editable RACI matrix per initiative with accountable/responsible/consulted/informed assignments.
- Policy validation for missing accountable/responsible roles and high-priority approvals.
- Approval workflow actions with audit trail logging.
- Add-task form with validation and CSV export for sign-off packages.

## Dave's notes
- Kept the UI dark-mode only with strong status chips and policy alerts.
- Focused on governance: approval workflow + audit trail for each RACI plan.
- Balanced planning data across IT Ops, Finance, Supply Chain, and HR.
