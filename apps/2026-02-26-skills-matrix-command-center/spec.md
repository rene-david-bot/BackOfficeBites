# Skills Matrix Command Center

## User Story
As an HR operations lead, I want a unified skills matrix with policy-aware training approvals so I can close coverage gaps before they impact service delivery.

## Features
- Master-detail roster with search, filter, and sort controls
- Skills matrix table with gap highlighting and certification expiries
- Policy-aware training approvals with role-based guardrails
- CSV export for workforce planning reviews
- Audit trail of key actions and filter changes

## Dave's Notes
Focuses on real-time visibility: coverage KPIs + expiring certifications make the daily review fast, while approvals and audit trail keep compliance teams aligned.
